# GitHub Pages + сервер на ПК

Дата переноса: 11 сентября 2026 года.

Публичный сайт: https://vsnp-moscow.github.io/np/

## Как устроено

- GitHub Pages публикует только каталог `frontend` в отдельной ветке `gh-pages`.
- Node.js API работает на этом ПК: `http://127.0.0.1:4100`.
- PostgreSQL 18.4 работает только на `localhost:5433`, база `navigator`.
- Приложение подключается отдельной ролью `npapp` без прав суперпользователя.
- Бесплатный SSH/HTTPS-туннель localhost.run передаёт запросы в API. Входящие порты роутера открывать не нужно.
- Адрес туннеля публикуется в `endpoint.json` ветки `gh-pages`. При открытии страницы интерфейс получает актуальный адрес из GitHub. После смены туннеля уже открытую вкладку нужно обновить.
- SmartAPI вызывается сервером. Ключ не публикуется вместе с фронтендом. Почтовый relay остаётся внешним сервисом.

## Запуск и остановка

В Планировщике заданий зарегистрировано `NavigatorPedagoga-LocalServer`, запуск после входа пользователя `admin` в Windows. Сервер работает в фоне; открытый Codex или браузер для него не нужен.

Ручной запуск из PowerShell:

```powershell
Start-ScheduledTask -TaskName NavigatorPedagoga-LocalServer
```

Остановка:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\admin\Documents\Codex\2026-09-09\new-chat\work\np-remote\scripts\local\stop.ps1"
```

Остановка штатно завершает API, туннель и PostgreSQL. Она может занять до минуты. Повторный запуск снимает флаг остановки. Не запускайте старый `start-local-smartapi.ps1` для этой версии: он использует другой SQLite.

## Проверка и восстановление

```powershell
Invoke-RestMethod http://127.0.0.1:4100/api/health
Get-Content C:\Users\admin\Documents\NavigatorPedagoga\runtime\logs\supervisor.log -Tail 20
```

Для ручного резервирования:

```powershell
node "C:\Users\admin\Documents\Codex\2026-09-09\new-chat\work\np-remote\backend\scripts\local-backup.mjs" "C:\Users\admin\Documents\NavigatorPedagoga"
```

Скрипт не перезаписывает уже готовый дамп за сегодняшний день. Дампы имеют формат PostgreSQL custom и открываются `pg_restore`. Восстанавливайте их сначала в отдельную пустую базу, проверяйте данные, только затем переключайте `DATABASE_URL`. Не копируйте работающий каталог `pgdata` как способ резервирования.

Для восстановления кода можно распаковать `project.zip` или клонировать `repository.bundle`. После восстановления кода выполнить `npm ci` в `backend`. Настройки восстанавливаются из закрытой копии `.env`, не из GitHub.

## Облачная запасная версия

Render и Supabase сохранены: https://navigator-pedagoga-api.onrender.com/

После переноса локальная и облачная базы независимы. Новые действия в GitHub Pages сохраняются на ПК и не копируются автоматически в Supabase. Переключение на облако без переноса свежего дампа покажет старое состояние. Автоматического переключения на другую базу при обрыве туннеля нет.

## Ограничения

- При выключенном ПК, выходе из Windows, сне или потере интернета API недоступен. Статическая страница GitHub Pages остаётся доступной. Автозапуск выполняется после входа в Windows, не до него.
- Бесплатный localhost.run меняет доменные имена, ограничивает скорость и не даёт гарантии непрерывной работы. При обрыве SSH процесс перезапускается; публикация адреса может занять несколько минут.
- На момент настройки автоматический сон в текущей схеме питания уже был отключён; настройки питания не менялись.
- Cloudflare Tunnel был проверен, но TLS-соединения к его узлам в текущей сети не установились. Поэтому используется localhost.run.
- Доступ проверяется из текущей сети ПК. Это не гарантия доступности GitHub, туннеля и SmartAPI у всех провайдеров РФ. Изменение сетевого подключения или VPN требует повторной проверки.
- Бесплатность инфраструктуры не отменяет квоты выбранного API ИИ.
